# Finance Tracker

Учебный сервис управления личными финансами: транзакции хранятся в PostgreSQL, фильтруются по периоду через Spring Data JPA, а бизнес-правила расширяются спецификациями/JPQL.

## Запуск
```bash
docker compose up -d postgres
mvn spring-boot:run
```
API: `GET /api/transactions?from=2026-01-01&to=2026-01-31`, `POST /api/transactions`.

## Что демонстрирует
- бизнес-задача: видеть расходы и находить категории за период;
- JPA, даты и PostgreSQL; следующий шаг — агрегаты статистики и CSV-экспорт;
- тестовый контур Spring Boot и GitHub Actions CI;
- проблема для разбора в портфолио: оптимизация фильтра запросом по индексированным датам вместо фильтрации в памяти.

Проект создан для IntelliJ IDEA и Java 21.
